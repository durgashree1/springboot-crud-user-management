Spring Boot CRUD User Management

A simple and clean Spring Boot CRUD application for managing users.
This project demonstrates how to build REST APIs using Spring Boot with standard CRUD operations.

🚀 Features

Create a new user

Get all users

Get user by ID

Update user

Delete user

REST API responses in JSON format

Layered architecture: Controller → Service → Repository

🔧 Tech Stack

Java 17+

Spring Boot

Spring Web

Spring Data JPA

MySQL (or H2 if used)

Maven
